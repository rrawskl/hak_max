# Источники данных

`data/programs.json` содержит 8 вымышленных программ «Учебный набор ДЕЛО». У каждой `data_kind=synthetic`, `source_url=null`, официальная проверка не заявлена. Даты при первом seed считаются от `DEMO_BASE_DATE` или текущего дня и больше не сдвигаются повторным seed. Есть положительный пример, неизвестное условие, обязательный отказ, закрытый приём, программа без суммы и программа без срока. Seed также создаёт профиль «Мастерская ДЕЛО» с неизвестной налоговой задолженностью и не перезаписывает изменённый профиль при повторном запуске. Формат всего каталога проверяется до записи в БД; ошибочные правила останавливают импорт.

Для реального каталога нужны подтверждённые первичные источники каждого оператора, URL, дата проверки и дата следующего обновления. Без них уверенный статус не показывается. Synthetic-записи не выдаются production API. Учебные правила не служат рекомендацией обращаться за конкретной мерой.
