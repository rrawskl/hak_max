# Сценарий демонстрации

1. Запустите локальный стенд по README и откройте `http://localhost:5173` на телефоне или компьютере.
2. Заполните профиль учебной компании: ИП, Санкт-Петербург, 3 сотрудника, регистрация более года назад, цель «Оборудование», задолженность «Не знаю».
3. В карточке «Учебная компенсация оборудования» увидите `check_needed`: 4 из 5 обязательных условий проверены, вопрос задолженности неизвестен.
4. Выберите будущую дату подготовки, включите напоминание и создайте план. В чек-листе появится отдельное уточнение задолженности.
5. Отметьте пункт, обновите страницу, затем откройте тот же план в другом окне. Отметка и версия сохраняются. Повторное создание активного плана не проходит.
6. Нажмите «Тестовое напоминание через 60 секунд». В локальном mock режиме worker покажет статус «Симуляция»; это не реальная доставка в MAX.

Для демонстрации жюри отдельно проверьте реальный бот, Mini App, два клиента MAX, HTTPS и получение сообщения с токеном владельца. Эти шаги не заменяются локальным demo.
