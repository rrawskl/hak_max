# Архитектура

React/TypeScript Mini App использует React Router, TanStack Query и CSS Modules. Компоновка зависит от ширины окна, а MAX Bridge изолирован в `frontend/src/api.ts`. Raw `initData` уходит на backend; `initDataUnsafe` не служит доказательством личности. Demo-вход доступен только по явному флагу в development.

FastAPI проверяет MAX подпись, создаёт короткую серверную сессию и извлекает пользователя из Bearer token на каждом маршруте. PostgreSQL 16 хранит профиль, учебный каталог, plans/items, idempotency keys, bot updates и notification outbox. В локальных Python-тестах используется SQLite. Alembic запускается процессом `init` до backend и worker. Seed добавляет 8 синтетических программ только при `SEED_DEMO=true` вне production.

Правила считаются только backend: обязательный fail блокирует, неизвестное обязательное условие даёт `check_needed`, закрытый приём даёт `closed`. План хранит snapshot программы; изменение версии каталога показывается отдельно, отмеченные пункты сохраняются. Изменения профиля/плана защищены версиями и 409. Уникальный индекс запрещает два активных плана пользователя по одной программе.

Возраст бизнеса — число полных календарных месяцев: разница годов и месяцев минус один, если текущий день месяца меньше дня регистрации. Например, 31 января → 28 февраля даёт 0 полных месяцев. Дедлайн сравнивается по дате Europe/Moscow; напоминания сохраняются в UTC.

Worker из того же backend image выбирает готовые уведомления из БД, берёт lease, выполняет отправку через MAX adapter и записывает результат. В mock режиме результат `simulated`. В реальном режиме используются официальный webhook и POST /messages; timeout отмечается `uncertain`. В MVP запускается один экземпляр worker.
